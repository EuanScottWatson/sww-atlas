# Holiday tracker requirements

- The app opens directly on the user's local network. Do not add login, passwords, or account setup.
- Map pins open Wikipedia place overviews. Editing requires an explicit Edit trip action.
- Keep trip details read-only until the user chooses Edit trip.
- Clicking outside any popup/dialog/temporary place panel dismisses it. Preserve normal interaction inside it and support Escape.
- Preserve imported trip data, manual corrections, source photos, SQLite storage and backups.
- The top navigation and month/agenda/year calendar replace the old sidebar and spreadsheet-style weekly screen.
